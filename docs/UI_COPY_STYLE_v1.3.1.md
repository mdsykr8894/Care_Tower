# Care Tower — UI Writing Style

## Voice
Care Tower speaks like a polished cozy educational game, not a technical prototype. Use **English for compact game UI terms**, and **natural Bahasa Melayu for instructions and helpful details**. The mix should feel intentional, not randomly translated.

## Core wording

| Surface | Approved heading/action | Support copy |
|---|---|---|
| Home | Quiz Meets Arcade · Care Tower | Susun blok dengan tepat, jawab 10 soalan dan kejar tempat teratas di leaderboard! |
| Join | Nickname untuk leaderboard · Join Game | One game · One leaderboard · No account needed |
| Waiting | You're All Set! | Hi, [nickname]! Tunggu sebentar, game akan bermula tak lama lagi. |
| Stacking | Drop the Block | Tap skrin atau tekan Space |
| Quiz | 10 Questions | Pilih jawapan paling tepat. You've got this! |
| Quiz feedback | Correct! / Good try! | +70 points / 0 quiz points |
| Stacking feedback | Perfect! / Great! / Good! / Nice save! | +points |
| Finished | Well Played! · Tower Complete! | Menara dah siap! Semak skor dan lihat kedudukan anda. |
| Player rankings | Leaderboard | Ranking akhir akan dikemas kini apabila masa tamat. |
| Presenter lobby | Ready to build your tower? | Scan QR, pilih nickname dan bersedia untuk 10 questions + 10 blocks! |
| Presenter live | Game On! · Live Leaderboard | Live scores · Every point counts! |
| Winners | Care Tower Champions! | Great game, everyone! Terima kasih kerana bermain. |
| Review | Let's Recap · Question Review | Lihat jawapan audiens dan penjelasan. |

## Do
- Keep key actions short: Join Game, Start Game, Drop the Block, Pause, Resume, Reset.
- Keep user guidance in short Malay sentences.
- Retain academic questions and the professional teacher–PDRM context unchanged.
- Keep care, privacy and safety messages grounded; do not trivialize the school harassment scenario.

## Don't
- Use `demo`, `prototype`, `server`, `localhost`, Vercel or developer-facing directions in visible game text.
- Force translation of standard arcade terms such as Perfect, Score and Leaderboard.
- Add decorative phrasing that makes core actions harder to understand.

The Solo Play mode is a legitimate way to play individually; development-only instructions remain in the README.
